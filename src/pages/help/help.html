Pin any message or screenshot into a collection, then find and copy it again in seconds. Everything is stored on this device only.

Keyboard shortcuts

These work on any website, you do not need to open the popup first.

ShortcutWhat it does
Alt+Shift+EOpen the popup, the same as clicking the extension icon. Select text on the page first and it is filled into the message box.
Alt+Shift+OOpen the full board, the corkboard with one column per collection.
Alt+Shift+CCapture an area. Drag a box over any part of the page. An action bar then lets you pin, copy, or download the screenshot (see Screenshot capture below).
Alt+Shift+FQuick find. Opens a small search window to find a pin and copy it (see below).

Right click menu

The fastest way to save text from a web page.

  1. Select the text you want to keep on any web page.
  2. Right click on the selection. You will see an option named Pin "your selected text" to…
  3. Hover over it. A list opens with every collection you have, for example Marketing, Scripts, Personal.
  4. Click a collection. The text is saved there instantly and the extension icon briefly shows OK.

What each item in the menu means

Menu itemWhat happens
Pin "…" to…The main entry. It only appears when text is selected, it does not show on an empty right click.
A collection nameSaves the selected text into that collection.
＋ New topic…Opens the full board and asks you to name a new collection. Your selected text is saved into it right after you name it.

New, renamed, and deleted collections update in this menu automatically. The menu does not work on browser pages such as chrome:// or the Chrome Web Store, and it does not capture screenshots, use Alt+Shift+C or the Capture button for that.

Screenshot capture

Press Alt+Shift+C (or the Capture button in the popup), then drag a box over the part of the page you want. When you let go, the box stays on screen with its size shown above it, and a small action bar appears below it.

ButtonKeyWhat it does
Collection listChooses where Pin saves the image. It starts on the collection you used last.
PinEnterSaves the screenshot on your board.
CopyCtrl + CCopies the image so you can paste it into a chat, email, or document.
DownloadCtrl + SSaves a PNG file to your Downloads folder.
✕EscCancels without saving anything.

Drawing on the screenshot

A column of tools appears next to the selection. Click a tool, then draw inside the box. Click the same tool again to switch it off.

ToolHow to use it
↗ ArrowDrag from where the arrow starts to where it should point.
▭ BoxDrag to outline an area.
✎ PenDraw freehand while holding the mouse button.
T TextClick where the text should go, type, then press Enter. Esc inside the text box discards it.
ColorsClick a color dot before drawing. It applies to the next thing you draw.
↶ UndoCtrl + Z removes the last drawing.

Everything you draw is included when you Pin, Copy, or Download. Drawing a new selection box clears the drawings.

Not happy with the box? Just drag again to draw a new one. The action bar is hidden before the screenshot is taken, so it never appears in the picture. Capture does not work on browser pages such as chrome:// or the Chrome Web Store.

Getting text into the extension

  • Select text, then open the popup. The selection is filled in the message box for you.
  • Paste button in the popup fills the message box from your clipboard in one click.
  • Choose a collection and press Pin. The popup remembers the last collection you used.

Tags and stars

  • + tag on any pin adds tags. Separate several with commas or spaces. Click the × on a tag to remove it.
  • On the full board, the tag bar filters every column. Click the tag again to clear the filter.
  • The board search box matches text and tags. Start with # to match tags only.
  • The ☆ star keeps a pin at the top of its collection, and first in Quick find.
  • On the board you can also drag pins to reorder them or move them to another collection.

Backup and restore

Use the Export and Import buttons at the top of the full board.

ButtonWhat it does
ExportDownloads one file named captain-pin-board-DATE.json with all your collections, text pins, image pins, tags and stars.
Import, MergeAdds the pins from the file that you do not already have. Nothing you have now is deleted, and importing the same file twice does not create duplicates.
Import, Replace allDeletes your current pins and restores exactly what is in the file. You are asked to confirm first.

To move your pins to another computer, Export here, copy the file across (email, Drive, USB), install the extension there and choose Import, then Merge. Keep a backup file somewhere safe before you remove or reinstall the extension.

Tips and fixes

  • Capture does nothing: browser pages (chrome://, the Web Store) cannot be captured. Try a normal website.
  • Paste button fails: allow clipboard access if Chrome asks, or paste with Ctrl+V.
  • Your data lives only in this browser. Removing the extension deletes it, so Export a backup now and then.
